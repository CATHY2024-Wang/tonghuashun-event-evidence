# 事件证据工作台

面向跟踪自选股的个人投资者和初级研究员。产品帮助用户在看到新公告、报道或传闻时，核对它是否属于已关注事件、原始来源在哪里、具体哪项主张改变，以及截至某一披露日能确认什么。它不提供买卖建议。

## 在线产品与演示

- Web URL：[事件证据工作台](https://event-evidence-cathy-2026.jscsjeremy.chatgpt.site)（公开可访问）。
- 源代码：[GitHub 仓库](https://github.com/CATHY2024-Wang/tonghuashun-event-evidence)。
- 演示视频：[139 秒 MP4](demo/event_evidence_demo.mp4)；[录制与复现说明](demo/README.md)。视频实拍公开站点，含 DeepSeek 在线抽取与用户确认。
- 最短操作路径：打开「高新发展拟收购华鲲振宇」→点击「回放至 4 月 18 日」→点击「导入新材料」→「填入已核验的 4 月 19 日公告演示样本」→「提取主张并建议归属」→确认归入华鲲振宇事件→查看「预计难续」变为「原方案终止」、时间线、公告原文及站内通知。
- 手工操作：也可粘贴其他材料并选择归入现有事件或新建事件。用户导入材料始终标为「待复核」，不会自动覆盖已核验的官方结论。
- 扩展事件：在「发现候选公告」输入深市 6 位股票代码、披露日期范围和可选的**标题**关键词。先打开巨潮原始 PDF 核对，再将可核查的原文片段粘贴进导入表单、使用 AI 抽取并由人确认事件归属。搜索结果本身只是公告候选，不会自动建立事件、主张或通知。

## 本地启动

需要 Node.js 22.13+。在项目目录执行：

    npm ci
    cp .env.example .env.local
    # 在 .env.local 内填写 DEEPSEEK_API_KEY，不要提交该文件
    npm run dev

访问命令行打印的本地 URL。未配置密钥时，真实案例的浏览、历史回放、演示样本导入、人工填写主张、事件归属确认、版本变化及站内通知仍可操作；页面会明确显示在线模型不可用，演示样本使用已人工核验的索引，不伪称模型结果。

## 核心设计

1. **来源与主张分离**：一篇材料可以包含多条可核验主张。「事实陈述 / 观点 / 推测 / 传闻」描述文本性质；「已确认 / 待复核 / 被后续材料取代」描述核验状态。事实语气不自动等于事实成立。
2. **先找事件，再由人确认**：公司、动作、交易标的和时间共同构成合并线索。同一上市公司同日披露的华鲲振宇收购与倍特期货股权出售被分成不同事件。系统只建议归属，用户可改选或新建。
3. **保留版本和四类时间**：事件发生、对外披露、系统收录、来源修改分别保存；缺失则显示未知。历史回放只使用截至所选日期已披露且人工核验的资料，不能把 4 月 19 日才公告的终止结果写到 4 月 18 日的公开信息里。同一 URL 的正文和更新时间均变化时，保存为可回看的待核验修订版。
4. **结论变更才提醒**：演示回放应用真实终止公告后，站内通知显示旧状态、新状态和 GS-06 原文依据。用户导入否认、更正或已过期材料时，生成指向具体主张的待复核提示；浏览器重新打开、重新可见或保持开启时会复查到期日期。重复应用同一已核验公告不会产生新版本或通知。
5. **来源独立性**：三条新闻保留其原始公告来源组。转载公告不能视为多份独立事实证据；新闻摘要遗漏的限制条件以原公告为准。

## AI、程序规则与人的分工

| 环节 | 作用 |
| --- | --- |
| DeepSeek deepseek-chat（公开部署已配置 Secret） | 对用户粘贴的材料提取实体、动作、标的、原子主张、精确引文及事件归属建议。原文按不可信数据处理；模型可返回“不确定”，由用户确认归属。 |
| 服务端校验 | 限制输入长度；要求每条引文确实出现在输入正文中；不合格主张被移除；接口失败明确报错。密钥只放服务端环境变量。 |
| 规则与已核验资料包 | 对原始公告状态执行可回放的迁移；按交易标的区分事件；识别相同 URL/文本；保留四种时间与转载来源关系。 |
| 用户 | 核对模型建议、选择归属、决定是否导入。用户提供的材料不会自动升级为经官方证实的结论。 |

模型并不直接访问 iFinD 或扶摇，也不自动从粘贴的 URL 抓取全文。用户须提供可核对的原文片段；链接用于溯源。DeepSeek 调用仅发送用户在导入表单填写的标题、材料类型和文本，不发送本地关注列表或密钥。

## 新公告发现与导入

公开站点提供按需的巨潮资讯**深市公告候选检索**。用户指定股票代码和披露日期区间，可选标题关键词；服务端从巨潮公开股票代码表解析机构标识，再请求其历史公告列表。候选卡仅展示公告标题、披露日期、发布公司和巨潮 PDF 链接。关键词只匹配公告**标题**，不搜索 PDF 正文；零结果不代表这家公司没有相关事件。沪市股票、新闻、研报、互动问答和市场传闻不在该检索范围。

检索结果中已在预置资料包内的公告会指向现有档案。未收录公告可带入导入表单；标题、日期、发布者和链接可预填，**原文片段须由用户查看 PDF 后自行摘录**。AI 只分析用户提交的片段并建议归属，最终由用户决定归入已有事件或新建事件。搜索失败或上游暂不可用时仍可手工粘贴材料。该功能是按需查询，没有后台自动监控或推送。

## 数据来源与可追溯性

资料包含 6 份高新发展关于华鲲振宇交易的巨潮原始公告、3 篇新闻转述、1 份同公司不同事项的巨潮公告。每条记录保留 URL、披露日期、短引文、PDF 页码或网页来源组，见 [案例来源](docs/CASE_SOURCES.md) 与 [机器可读资料包](data/seed_sources.json)。原始材料在 2026-09-24 逐份核对；公告列表提供的是**披露日期**，不能据此声称精确发布时刻。新闻时间若页面只有本地时钟显示，其时区推定口径在数据中注明。

截至资料包最后披露日 **2024-04-19**，能确认的结论是：2023 年披露的购买华鲲振宇 70% 股权重组方案已终止；公司另有推动相关股权收购的表态，但能否取得控制权、时间与方案仍不确定。此结论**不代表已核验 2026 年的现实最新状态**。高投电子集团持有标的公司股权，不等于上市公司已经完成收购。

## 数据保存与接口

- 预置案例随源代码发布。
- 用户新导入的材料及站内通知仅保存在**当前浏览器本地**，没有登录、跨设备同步或后台定时抓取。过期检查依赖打开该页面，不会在浏览器关闭时发送推送。清除浏览器站点数据会清除个人导入记录，不影响预置案例。
- iFinD MCP 和扶摇有官方接口，但本次未取得可供公开 Web 产品使用的接口密钥与数据展示授权；扶摇资讯事件库目前也未开放外部接入。因此线上没有声称来自它们的实时行情、财务、新闻或公告数据。核查依据与后续接入顺序见 [数据连接决策](docs/DATA_CONNECTOR_DECISION.md)。
- 巨潮公开检索只用于发现公告标题和原文入口，不等于已核验公告内容。站点对上游接口的可用性没有服务级承诺；关键结论仍以人工核对的原文片段和来源链接为准。
- 后端调用 DeepSeek 需要 DEEPSEEK_API_KEY。所有 .env 文件已被 Git 忽略；不要将密钥写入代码、截图或演示视频。

## 已知边界与未做事项

- 预置案例的人工核验截止 2024-04-19；按需检索可能发现后来披露的公告，但不会自动刷新档案结论。过期信息应提示复核，不能自动判为虚假。
- 用户粘贴的外部链接未由服务器自动下载或验证真伪；其主张保持「待复核」。缺来源、冲突或模型失败时不生成肯定结论。
- 用户填写的“原文更新时间”与修订正文尚未由服务器自动核实，修订版本始终标为待复核；预置资料只存核验引文，无法与未缓存的整篇历史原文逐字比较。
- 演示回放是对真实已披露公告的历史重放，不是虚构历史；否认、更正、过期等未在本案真实链路出现的分支只作为显著标记的测试场景，不伪称事实。
- 未做行情影响验证、股价因果归因、确定性涨跌预测、收益承诺、自动交易建议和多用户协作。
- 事件识别在当前样本中以标的与动作规则辅助模型建议，并由人确认；未在大规模多行业语料上证明泛化准确率。
