## 浏览器回归记录

2026-09-24 使用全新无 Cookie 的 Playwright Chrome 上下文访问公开 v3（源码提交 `5c9f822`）：起始 `localStorage=null`，页面 GET 200。输入显著标记的匿名模拟否认材料、原文链接留空，DeepSeek 返回 3 条候选主张；人工选择“否认”并关联 `C4` 后，本地 `sources=1`、`notices=1`，材料 `simulated=true`，主张卡与通知均有模拟／待复核标记。通知说明原主张仍为已确认，主结论前后逐字一致。再次输入完全相同标题与正文，页面提示“这份材料已在当前资料中，重复导入不会生成新版本或通知”，`sources=1`、`notices=1`。v2 曾在无 URL 情况下误收重复材料；v3 的全文判重修复了这一路径，并新增自动回归用例。模拟材料不代表真实历史，浏览器记录只保存在该测试上下文的 localStorage。

模型上游超时／5xx、原文链接失效、模型返回虚构引文被剔除等分支已有降级或待复核处理，但本次没有主动制造对应故障；它们只列为测试说明的待执行项，不计入通过数量。

## 异常与合规验收口径

- 外部材料缺原文链接、时间或引文时，保持待复核；不把系统抓取时间冒充事件发生时间。
- 模型返回无法在输入正文定位的引文时，服务端移除该主张。提示注入文本仅作为材料内容，不得改变抽取规则。
- 用户导入的材料不自动改写已核验官方结论；重复导入不生成新版本及通知。
- 产品展示证据与标的关系，不提供确定性涨跌预测、收益承诺或直接买卖建议。
- 真实案例没有独立的否认、更正或到期节点。相关分支按 VALIDATION_PLAN.md 以显著标记的模拟材料测试；未执行前不列为通过。
