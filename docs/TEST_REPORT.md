## 异常与合规验收口径

- 外部材料缺原文链接、时间或引文时，保持待复核；不把系统抓取时间冒充事件发生时间。
- 模型返回无法在输入正文定位的引文时，服务端移除该主张。提示注入文本仅作为材料内容，不得改变抽取规则。
- 用户导入的材料不自动改写已核验官方结论；重复导入不生成新版本及通知。
- 产品展示证据与标的关系，不提供确定性涨跌预测、收益承诺或直接买卖建议。
- 真实案例没有独立的否认、更正或到期节点。相关分支按 VALIDATION_PLAN.md 以显著标记的模拟材料测试；未执行前不列为通过。
