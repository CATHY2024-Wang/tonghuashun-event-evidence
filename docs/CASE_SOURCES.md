## 材料类型、时间与证据独立性说明

1. 公告表均为**上市公司原始披露**，新闻表为真实新闻转载/报道，未混入社交媒体传闻或虚构报道；公告中的“拟”“预计”“将”属于计划/预测表达，不能升级为完成事实。
2. 当前材料包有足够的官方版本演化和可展示的新闻转载链，可以先做可运行主链路。若后续加入研报或市场传闻，须逐条保存原始 URL、作者、发布日期、引用段落，并标明转载源头；新闻复述公告不能算第二份独立事实证据。**没有可靠原始 URL 的传闻不要造出来。**检索到的研报第三方转载存在明显错字、原件未核实，因此未纳入可引用证据。
3. `occurred_on`（如 2024-04-18 董事会决议）、`disclosed_on`（2024-04-19 公告）、`fetched_on`（系统真实拉取日）、`updated_at`（来源修订日）是不同字段。公告只显示披露日期时，时间精度标为 `date`；未知值保留 `null`。不得把 PDF 路径日期当发生日期。
4. 2024 年后可能还有关于标的公司收购的**新交易事件**。新公告是否属于原方案的版本演化，需依据正式协议、交易标的、交易对方和方案编号判断，不能仅凭“高新发展+华鲲振宇”自动合并。
