## 运行时 AI 的作用边界

- 只处理用户在导入表单主动输入的标题、材料类型、文本；服务端不传 API Key 给浏览器。
- 来源文本可能包含指令，提示词明确把它当不可信数据。输出仅是候选，不能替代公告原文或人的归属确认。
- DeepSeek 故障、超时、缺密钥或输出结构不合格时，产品明确降级。已核验演示材料可使用人工核对过的索引；任意用户材料可手工填写主张。界面标明运行模式。
- 模型不会自动验证粘贴 URL 是否真实，不会凭空补充发生时间或股价影响。

## 实测边界

本次真实模型调用的返回引文均可定位，没有触发“移除无法定位引文”的分支；该分支是代码防护，不能当作实测成效。上游超时与 5xx 尚未主动制造。未核验的用户材料和模拟传闻仍需人工判断来源，不能因模型给出 `事实陈述` 就提升为官方确认。运行记录、异常状态和人工修正见 [模型调用记录](AI_MODEL_RUN.md)。
